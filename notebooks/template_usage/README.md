# Template Usage And Visualisation

This folder contains the current practical notebooks for using already-built warp coefficient files.

Start here:

1. `create_usable_template_lightcurves.ipynb`

That notebook loads `warpcoeff_v3`, samples templates with `WarpfitTemplateLoader`, compares colour modes, measures peak colour, and can turn one warped `sncosmo.Model` into a light-curve table.
